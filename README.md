# Swiggy-Restaurant-Data-Analysis

This project focuses on analyzing Swiggy restaurant and food delivery data using Python and data visualization tools. The objective is to extract meaningful insights from raw restaurant data, perform exploratory data analysis (EDA), clean and transform the dataset, and visualize important trends related to ratings, cuisines, pricing, and restaurant categories.

The project is designed to be recruiter-friendly and demonstrates practical data analytics, data cleaning, and visualization skills using real-world food delivery data.

---

# Dataset

**Source:** Swiggy Restaurant Dataset (CSV Format)

### Content Includes:

- Restaurant Name  
- Location  
- Cuisine Type  
- Restaurant Ratings  
- Number of Ratings  
- Offer Name  
- Pure Veg Status  
- Average Price / Cost  
- Delivery & Restaurant Information
